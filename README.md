# Yao Lu — Academic Website

Personal academic website for Yao Lu, Ph.D. student in Computer Science and Engineering at The Ohio State University.

Hosted with GitHub Pages at https://adobely.github.io/ . Static HTML, CSS, and JavaScript; no build step or external dependencies.

## Editing

- `index.html`: biography, research interests, publications, education, experience, projects, and awards.
- `styles.css`: responsive layout, colors, typography, and print styles.
- `assets/Yao-Lu-CV.pdf`: downloadable CV.
- `script.js`: active section navigation and copyright year.

For local preview, serve this directory using a static HTTP server. In repository Settings → Pages, deploy from the `main` branch and `/ (root)` directory.

The publications section lists venue names and under-review status only. It does not represent acceptance. Update statuses and ensure compliance with the relevant conference edition's anonymity policy before adding identifying paper details.
